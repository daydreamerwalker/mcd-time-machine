# 情感地图（Emotion Map）

本文件是「情感语录卡片」与「特殊日期回忆」功能的文案规范。当用户选择一种情感时，按其风格指引生成文案；当用户选择「AI 自由生成」时，从数据中提炼情绪并匹配最接近的一种情感风格。

## 通用文案原则

1. 文案必须**引用用户真实数据**（餐品名、门店、时间、金额、次数），禁止空洞抒情。
2. 每段文案 20–60 字，口语化、有网感，像朋友说话，不像品牌广告。
3. 可以玩麦当劳梗（麦门、疯狂星期四、穷鬼套餐、麦乐菌、金拱门），但不过度玩梗。
4. 数字优先用阿拉伯数字；「第 1 次」「第 37 个夜晚」比「很多次」更有感染力。
5. 涉及营养数据时只描述事实与选择，不做健康评判（参考 CONTEST_DECLARATION 的使用提示）。

## 情感清单

### 1. 治愈（healing）
- **风格**：温暖、柔软、慢节奏，像深夜食堂的一盏灯。
- **配色**：暖黄 #FFC72C → 奶白 #FFF6E0，深棕文字 #4A2C0F。
- **Emoji**：🌙 🍟 🧸
- **示例**：那天加班到十一点，是麦乐鸡告诉你：辛苦了，先吃饭。

### 2. 开心（happy）
- **风格**：明亮、跳跃、庆祝感，语气上扬。
- **配色**：麦当劳红 #DA291C → 亮黄 #FFC72C，白色文字。
- **Emoji**：🎉 🍔 ✨
- **示例**：今年你吃了 42 个汉堡，快乐指数爆表，麦门信徒实锤！

### 3. emo（melancholy）
- **风格**：低饱和度、留白、克制的忧伤，不卖惨。
- **配色**：雾蓝灰 #8A9BA8 → #E8ECEF，深灰文字 #3B4650。
- **Emoji**：🌧️ 🥤 💧
- **示例**：第 7 杯可乐见底的时候，好像有些情绪也跟着咽了回去。

### 4. 孤独（lonely）
- **风格**：安静、自我对话，一个人的仪式感。
- **配色**：深夜蓝紫 #2B2D42 → #8D99AE，浅色文字 #EDF2F4。
- **Emoji**：🚶 🌃 🍟
- **示例**：一个人吃薯条的好处是：不用分享，也不用假装客气。

### 5. 热血（passion）
- **风格**：短句、排比、力量感，像赛前动员。
- **配色**：烈焰红 #E63946 → 深黑 #1D1D1D，白字。
- **Emoji**：🔥 💪 ⚡
- **示例**：凌晨一点的巨无霸，是给野心加的油。吞下去，继续干！

### 6. 摆烂（chill）
- **风格**：躺平哲学、自嘲、反内卷，理直气壮地懒。
- **配色**：抹茶绿 #A8C686 → 米白 #F5F1E8，深绿文字 #3D5229。
- **Emoji**：🛋️ 😴 🥱
- **示例**：不是我不想做饭，是冰箱先动的手。今天的 KPI 是：把薯条吃完。

### 7. 甜蜜（sweet）
- **风格**：恋爱感、双人份、冒泡泡。
- **配色**：樱花粉 #FFB3C6 → 奶白 #FFF0F3，玫红文字 #A4133C。
- **Emoji**：💕 🍦 🥰
- **示例**：第二杯半价的甜筒，终于有人和你一起消灭了。

### 8. 怀旧（nostalgic）
- **风格**：旧时光、老味道、时光对比（今年 vs 当年）。
- **配色**：做旧牛皮纸 #D9B382 → #F4E8D8，棕文字 #6B4226。
- **Emoji**：📻 🕰️ 🍦
- **示例**：从 6 块钱的甜筒到 8 块，涨价的是价格，不变的是第一口的快乐。

### 9. 感恩（grateful）
- **风格**：认真说谢谢，具体到事，不煽情。
- **配色**：暖橙 #F4A261 → 米白 #FDF6EC，深棕文字 #5C3D1E。
- **Emoji**：🙏 💛 🧡
- **示例**：谢谢那个雨天准时送达的骑手，和一份没怎么洒的可乐。

### 10. 叛逆（rebel）
- **风格**：反套路、小疯狂、明知故犯的快乐。
- **配色**：荧光紫绿 #7B2FBE → #06D6A0，白字。
- **Emoji**：😈 🃏 🚀
- **示例**：凌晨三点吃双层吉士汉堡怎么了？规则就是用来打破的，胃也是。

## 情感 → 卡片渲染参数

`render_mood_cards.py` 接受 `--emotion <key>`，key 取值为上表括号内的英文（healing / happy / melancholy / lonely / passion / chill / sweet / nostalgic / grateful / rebel）。配色与 emoji 已内置，无需手动传颜色。

## 文案生成流程（Claude 执行）

1. 读取用户选择的情感 key（缺省让用户从 10 个中文名中选）。
2. 从规范化订单 JSON 中挑 2–4 个最强相关数据点（深夜订单、复购王、省钱记录、首单等）。
3. 按该情感风格写 1 段主文案 + 1 句副文案（8–16 字，可作卡片副标题）。
4. 主文案写入卡片中央，副文案放卡片底部，数据点作为卡片上的「小字注脚」自动展示。
5. 若用户要求多张卡片，为不同情感各生成一张，一次性传给渲染脚本。
