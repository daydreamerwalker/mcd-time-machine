# 年度麦麦报告 Playbook

「年度麦麦报告」参照网易云年度报告的叙事结构：**分章节滚动、大字金句、数据人格化**。本文件定义指标计算方式、章节顺序与金句写法。

## 数据来源（MCP 工具 → 指标）

| 指标 | 来源工具 | 说明 |
|---|---|---|
| 总订单数 / 总花费 | `order-list` + `mall-order-list` | 两类订单分开统计再合并；mall 订单按实付积分+金额计 |
| 最常点餐品 TOP3 | `order-list` 商品明细 | 按名称聚合数量 |
| 最常去门店 TOP3 | `order-list` | 按门店名聚合 |
| 月份分布 | `order-list` + `mall-order-list` | 按自然月分组，找峰值月 |
| 深夜订单 | `order-list` | 取餐/下单时间在 22:00–04:59 的订单 |
| 品类分布 | `order-list` 商品名 → 品类映射 | 见下方品类映射表 |
| 营养摄入 | `list-nutrition-foods` 按餐品名匹配 | 能量/蛋白质/脂肪/碳水/钠求和 |
| 积分收入 | `query-my-account` | 可用/累计/即将过期积分 |
| 省钱金额 | `query-my-coupons` + `order-list` 优惠字段 | 优惠券面额 + 订单优惠 |
| 活动参与 | `campaign-calendar` | 与订单日期交叉，标注「活动期间的订单」 |
| 首单日期 | `order-list` 最早一条 | 「一切的开始」章节用 |

## 品类映射表（餐品名 → 品类）

按关键词匹配，命中多个时取第一个：

- `burger` 汉堡主食：堡、汉堡、牛堡、麦香鱼、麦辣鸡腿堡、巨无霸、吉士、不素之霸、双层
- `chicken` 小食炸鸡：麦乐鸡、鸡翅、鸡腿、鸡块、炸鸡、脆汁鸡
- `fries` 薯条薯格：薯条、薯格、薯饼
- `drink` 饮品：可乐、雪碧、咖啡、拿铁、美式、奶茶、果汁、气泡水、牛奶、豆浆、麦炫酷
- `dessert` 甜点冰淇淋：甜筒、冰淇淋、圣代、派、蛋挞、麦旋风、蛋糕
- `breakfast` 早餐：早餐、猪柳蛋、早安、扒饼、热香饼
- `combo` 套餐：套餐、乐园餐、家庭桶、分享盒
- `other` 其他：玩具、周边、积分兑换商品、麦金卡等

## 章节结构（固定 10 屏，可删不可乱序；编号以渲染脚本为准）

1. **封面**：年份 + 用户昵称 + 「你的年度麦麦报告」+ 主标题金句
2. **CHAPTER 01 一切的开始**：首单日期、首单餐品、首单门店（衔接特殊日期专题同名章节）
3. **CHAPTER 02 干饭战绩**：总订单、总花费、总件数、打卡门店数 + 月度消费/订单组合图
4. **CHAPTER 03 本命之选**：最常点餐品 TOP3、最常去门店 TOP3
5. **CHAPTER 04 深夜食堂**：深夜订单数、最晚一单（按深夜时刻排序，02:47 优先于 23:50）、深夜挚爱
6. **CHAPTER 05 吃饭的方式**：到店取餐 / 麦乐送 / 得来速 / 商城订单分布
7. **CHAPTER 06 口味人格**：品类分布环形图 + 口味人格标签 + 营养摄入总览
8. **CHAPTER 07 省钱大师**：优惠券节省、可用积分、抽奖次数
9. **CHAPTER 08 年度金句**：把全年最戳的 3 个瞬间写成大字报
10. **THE END 结尾**：年度关键词 + 收尾金句 + 「明年见」

## 口味人格标签判定

按品类占比取 TOP1 品类，套用对应人格；营养数据用于润色描述：

- burger → 「堡族战神」
- chicken/dessert 双高 → 「快乐炸鸡收藏家」
- fries → 「薯条永动机」
- drink 占比 >30% → 「液体面包品鉴师」
- breakfast >5 单 → 「清晨自律人」
- 深夜订单 >10 单 → 「深夜食堂常客」
- 省券 >20 张 → 「麦麦省锦鲤」
- 默认兜底 → 「麦门全勤生」

## 金句写法

- 每章 1 句主金句：**具体数字 + 意外角度 + 情绪落点**。
  - 好：「今年你最晚的一单是凌晨 2:47，那个点的麦乐鸡，是夜宵也是勇气。」
  - 差：「你很喜欢吃麦当劳，消费了很多。」
- 金句必须可由数据推出，不允许编造无数据支撑的「最」。
- 语气默认温暖自嘲；用户选择情感时按 `emotion-map.md` 的风格覆盖默认语气。
