# 麦麦时光机 · MCD Time Machine

> 把一年的麦当劳消费数据，变成一部可以滚动的回忆录。
> 麦当劳程序员节创意开发大赛参赛作品 · 原创开发 · 非麦当劳官方产品

## 项目介绍

「麦麦时光机」是一个基于**麦当劳 MCP**（`mcd-mcp`）开发的 Skill。它读取用户近 12 个月的真实订单、营养、积分与活动数据，生成四种可分享的精美 HTML：

| # | 能力 | 说明 |
|---|------|------|
| 1 | **情感语录卡片** | 用户选择心情（治愈 / 开心 / emo / 孤独 / 热血 / 摆烂 / 甜蜜 / 怀旧 / 感恩 / 叛逆），AI 结合真实消费数据写文案，渲染成竖版分享卡片；每张卡片有专属配色与 emoji |
| 2 | **年度麦麦报告** | 对标网易云年度报告的深色滚动叙事页：封面 → 一切的开始 → 干饭战绩 → 本命之选 → 深夜食堂 → 吃饭的方式 → 口味人格 → 省钱大师 → 年度金句 → 明年见，共 10 屏 |
| 3 | **口味进化图** | 季度口味人格进化时间线、品类占比堆叠演变、月度热量/钠/蛋白质摄入曲线、新欢与旧爱对比、消费习惯画像（最爱下单日 / 均价 / 时段分布）与「进化预言」 |
| 4 | **特殊日期回忆专题** | 四个主题：**节假日专辑**（元旦/春节/情人节/劳动/端午/中秋/国庆/圣诞/双十一 + 活动日历）、**深夜食堂**（22:00–04:59 订单聚合）、**一切的开始**（首单）、**自定义纪念日**（用户指定日期，无订单时自动扩展前后 3 天）。文案可 AI 生成，也可由用户情感选择驱动 |

## 目标用户

- 想「复盘」自己一年麦麦消费的重度用户（麦门信徒）
- 喜欢年度报告仪式感、愿意分享到社交平台的年轻用户
- 想给特别的日子（生日、纪念日）做一份有趣纪念的用户

## 安装方法

### 1. 配置麦当劳 MCP（前置）

在 WorkBuddy【连接器】→【自定义连接器】→【配置 MCP】中填入（Token 替换为自己的）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

保存后在自定义连接器列表中**启用** `mcd-mcp`。

### 2. 安装 Skill

将 `mcd-time-machine/` 目录放入 Skills 目录（WorkBuddy 用户级路径为 `~/.workbuddy/skills/`），或直接使用仓库自带的打包产物 `dist/mcd-time-machine.zip`。

### 3. 使用示例

在对话中直接说：

- 「帮我生成 2026 年度麦麦报告」
- 「选『治愈』心情，给我做几张麦麦语录卡片」
- 「看看我的口味是怎么进化的」
- 「做一份特殊日期回忆，要有深夜食堂和情人节那天的订单」
- 「把 2026-05-20 设为我的纪念日，做一页回忆」

Skill 会自动：调用 MCP 拉取数据 → 询问昵称与心情 → 整理为规范化 JSON → 生成文案 → 渲染 HTML → 交付文件。演示数据中的地名（`XXX餐厅(1号店)`）与人名（`XXX`）均为占位符，接入真实 MCP 数据后自动替换为用户的真实门店与昵称。

## 视觉设计

麦当劳元素铺满的原创视觉体系（全部素材代码生成或 AI 原创绘制，无外部图片依赖）：

- **经典红黄**：#DA291C / #FFC72C 主色，暖黑描边 + 硬阴影贴纸风（去玻璃拟态）
- **麦当劳符号**：金拱门背景水印、雨棚斜条纹、棋盘格地面、小票条码、邮戳、「I'M LOVIN' IT」像素横幅
- **8-bit 像素人物**：汉堡 / 薯条 / 可乐 / 小丑四只精灵（`assets/images/px-*.png`），封面游行、角落探头、背景装饰
- **实物照片**：巨无霸 / 薯条 / 可乐 / 圣代 / 麦乐鸡 / 门店六张（`assets/images/ph-*.jpg`），以拍立得相纸形式嵌入对应章节
- **像素字体**：Press Start 2P（latin 子集 base64 内联）呈现所有数字与英文标题
- 素材由 `tools/prepare_assets.py` 生成/预处理（去水印、抠背景、量化压缩），可复现

## 技术要点

- **零依赖**：渲染器仅用 Python 标准库，输出单文件 HTML（内联 CSS + 内联 SVG + base64 图片/字体 + 原生 JS 滚动显现动画），可离线分享。
- **数据契约**：MCP 原始返回统一规范化为 `normalized.json`（见 `references/mcp-tools.md`），渲染器与数据源解耦。
- **只读安全**：全程仅调用只读工具（订单/营养/积分/券/活动日历），绝不创建订单、领券或抽奖。
- **降级策略**：MCP 不可用时用演示数据出图并明确标注；单项数据、图片、字体缺失时自动跳过对应装饰并注明，不影响生成。
- **素材可复现**：`tools/prepare_assets.py` 记录素材的生成参数与后处理流程（去水印、抠透明背景、量化压缩）。
